# FAZ 01 Implementation Plan

> **For agentic workers:** Use executing-plans for integration and dispatching-parallel-agents for the independent pure geometry task.

**Goal:** Gerçek mm geometrisiyle kapalı deck alanı, boşluk birleşimi ve net m².
**Architecture:** FAZ00 paths korunur ve sürüm2'de role/closed/name/kind ve layers/snap ayarlarıyla genişler. Saf geometri, editör işlemleri ve native UI ayrıdır. SQLite tablo yapısı aynı, JSON okuyucu v1→v2 kayıpsız dönüşür. Açık/geçersiz geometri kaydedilebilir taslaktır; sonuç gösterilmez.
**Tech Stack:** Mevcut Expo/Skia/Gesture/Zustand/SQLite + polygon-clipping (birleşim/fark).
**Spec:** docs/superpowers/specs/2026-11-05-faz01-request.md

## Global Constraints
- FAZ00 proje kayıtlarını koru. FAZ02/karkas hesaplama yok.
- mm koordinatlarını erken yuvarlama; yalnız UI sonuçlarını iki ondalık göster.
- Ölçü değişikliği seçili kenarın yönünü korur, kullanıcının seçtiği ucu sabitler ve diğer ucu taşır. Komşu kenarlar serbestçe güncellenir; kalıcı ölçü kilitleri sunulmaz. Geçersiz sonuç reddedilir.
- Tek dış alan; sınırsız isimlendirilmiş boşluk (Ev/Balkon/Havuz/Merdiven/Kolon/Kabin/Özel boşluk). FAZ00 ek çizgileri draft rolünde koru; kullanıcı dış sınır/boşluk olarak atayabilsin.
- Açık veya hatalı dış sınır/boşlukta kesin alan gösterme. Çakışan boşlukları birleşim olarak çıkar; dışarı taşanı reddet.

## Review Focus
- Eski JSON koordinatları, ölçüler ve ek yollar dönüşümde korunmalı.
- Görünmez katmanlar hesap sonucunu değiştirmemeli ve hit-test almamalı.
- Köşe taşıma/kenar düzenleme geçersiz veya dışarı taşan boşluk üretirse atomik reddedilmeli.
- Drag tek undo adımı; pinch vertex sürüklemesine dönüşmemeli.
- Açık dış alan veya boşluk için alan kartı sayısal kesin sonuç göstermemeli.
